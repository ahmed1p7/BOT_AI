# 📱 تشغيل البوت على Termux

تم تعديل البوت ليعمل بشكل مثالي على Termux مع ظهور رمز QR للتسجيل.

## 🛠️ خطوات التثبيت والتشغيل:

### 1. تثبيت المتطلبات الأساسية في Termux:
```bash
pkg update && pkg upgrade
pkg install nodejs
pkg install git
```

### 2. استنساخ المشروع:
```bash
git clone <رابط_المستودع_الخاص_بك>
cd BOT_AI-Yuna
```

### 3. تثبيت المكتبات:
```bash
npm install
```

### 4. تشغيل البوت (الطريقة الصحيحة):
```bash
npm run termux
```

## ✅ ماذا سيحدث عند التشغيل؟

1. سيقوم البوت بالاتصال بخوادم واتساب
2. ستظهر لك رسالة: `📱 امسح رمز الـ QR هذا بواسطة واتساب:`
3. سيظهر رمز QR في التيرمينال
4. افتح واتساب على هاتفك → الأجهزة المرتبطة → ربط جهاز
5. امسح رمز QR
6. بمجرد المسح، ستظهر رسالة: `✅ تم الاتصال بنجاح! البوت يعمل الآن.`

## ⚠️ ملاحظات مهمة:

- **لا تغلق تطبيق Termux** بعد تشغيل البوت، وإلا سينقطع الاتصال
- للحفاظ على البوت يعمل في الخلفية، استخدم تطبيق مثل `Termux:Boot` أو `nohup`
- إذا خرجت من الجلسة عن طريق الخطأ، أعد تشغيل الأمر `npm run termux` وسيتصل تلقائياً دون الحاجة لمسح QR مرة أخرى (طالما لم تحذف مجلد `auth_info_baileys`)

## 🔧 حل المشاكل الشائعة:

### المشكلة: لا يظهر رمز QR
**الحل:** تأكد من تثبيت مكتبة `qrcode-terminal`:
```bash
npm install qrcode-terminal
```

### المشكلة: البوت ينفصل فوراً
**الحل:** تحقق من اتصال الإنترنت، وأعد تشغيل الأمر

### المشكلة: يطلب مسح QR في كل مرة
**الحل:** لا تحذف مجلد `auth_info_baileys` الذي يحتوي على بيانات الجلسة
