# 🤖 GataBot-MD - بوت الواتساب المتقدم

بوت واتساب عربي متقدم يعمل على منصة Vercel باستخدام مكتبة Baileys. يوفر البوت مجموعة واسعة من الميزات بما في ذلك تحميل الوسائط، التكامل مع الذكاء الاصطناعي، إدارة المجموعات، والألعاب الترفيهية.

## 📋 الأوامر

### الأوامر العامة
- `!ping` - فحص حالة البوت
- `!info` - عرض معلومات البوت
- `!help` - عرض رسالة المساعدة

### أوامر الميديا
- `!yt [URL]` - تحميل فيديو يوتيوب
- `!play [اسم الأغنية]` - البحث وتشغيل الموسيقى

### أوامر الذكاء الاصطناعي
- `!gpt [prompt]` - الدردشة مع مساعد الذكاء الاصطناعي

### أوامر المجموعات
- `!groupinfo` - الحصول على معلومات المجموعة
- `!add [رقم]` - إضافة عضو إلى المجموعة
- `!remove [رقم]` - إزالة عضو من المجموعة

### الألعاب الترفيهية
- `!rps [حجر/ورقة/مقص]` - لعب حجر ورقة مقص
- `!guess [رقم]` - لعب لعبة تخمين الرقم
- `!tictactoe [موقع 0-8]` - لعب لعبة إكس أو
- `!tictactoe new` - بدء لعبة إكس أو جديدة
- `!trivia` - لعب لعبة المسابقات
- `!hangman` - بدء لعبة الرجل المشنوق
- `!memory` - لعب لعبة الذاكرة
- `!dice [مبلغ الرهان]` - لعب لعبة النرد مع الرهان
- `!chain` - بدء لعبة سلسلة الكلمات

## 🚀 النشر

### على Vercel

1. قم بعمل Fork لهذا المستودع
2. أنشئ مشروعًا جديدًا على [Vercel](https://vercel.com/)
3. استورد مستودعك الذي تم عمل Fork له
4. أضف متغيرات البيئة الخاصة بك في لوحة تحكم Vercel
5. انشر المشروع!

### متغيرات البيئة

- `OWNER_NUMBER`: رقم الواتساب الخاص بك (بدون +)
- `OPENAI_API_KEY`: مفتاح API الخاص بـ OpenAI (اختياري)
- `MONGODB_URI`: سلسلة اتصال MongoDB (اختياري)
- `SESSION_NAME`: اسم الجلسة لبيانات المصادقة

### التطوير المحلي

```bash
npm install
npm start
```

بعد التشغيل، امسح رمز الاستجابة السريعة المعروض في المحطة الطرفية أو قم بزيارة http://localhost:3000/qrcode للحصول على رمز الاستجابة السريعة في متصفحك.

## 🔌 نقاط نهاية API

- `GET /` - صفحة فحص الحالة
- `GET /qrcode` - صفحة رمز الاستجابة السريعة (عند الحاجة)
- `POST /send-message` - إرسال رسالة إلى رقم واتساب

## 🏗️ البنية المعمارية

يستخدم هذا البوت:
- [@whiskeysockets/baileys](https://github.com/WhiskeySockets/Baileys) - واجهة واتساب ويب API
- [Express.js](https://expressjs.com/) - إطار عمل الويب
- [Vercel](https://vercel.com/) - منصة النشر
- [MongoDB](https://www.mongodb.com/) - تخزين قاعدة البيانات الاختياري
